# Лабораторна робота №2 (Варіант 15)

## Структура та опис завдань
* **`labs/lab02/task1.py`** — об'єктно орієнтована модель управління обліковими записами, сесіями (`Session`), ієрархією користувачів (`User`, `Admin`) та аудитом безпеки (`AuditLog`) із безпечним хешуванням паролів.
* **`labs/lab02/task2.py`** — консольна утиліта для автоматизованого аналізу журналів привілейованого доступу (`sudo.log`). Реалізує регулярні вирази для парсингу, підрахунок статистики через `Counter`, логування подій та безпечну обробку винятків (`try-except`) під час читання файлів і збереження звітів.
* **`labs/lab02/main.py`** — єдина точка входу для запуску програм через інтерфейс командного рядка.

## Параметри запуску консольної утиліти (Завдання 2)
Для виконання аналізу логів утиліта використовує модуль `argparse` з такими аргументами командного рядка:
* *`--sudo-log`* — шлях до вхідного файлу журналів `sudo.log` (передбачено перевірку наявності файлу та перехоплення помилок типу `PermissionError` і `UnicodeDecodeError`).
* *`--alert-commands`* — шлях до файлу зі списком контрольованих або заборонених команд для виявлення аномалій та ризикованих дій.
* *`--out-json`* — шлях до файлу для експорту фінального звіту про результати аудиту у форматі JSON (з автоматичним створенням батьківських директорій та захистом від збоїв запису).

## Інструкції з запуску
Усі команди виконуються з коренем репозиторію в активному віртуальному середовищі з установленими залежностями з файлу `requirements.txt`.

### 1. Запуск першого завдання (демонстрація ООП)

python -m labs.lab02.main demo

### 2. Запуск другого завдання (аналіз логів з параметрами)

python -m labs.lab02.main analyze --sudo-log labs/lab02/data/data_v15/sudo.log --alert-commands labs/lab02/data/data_v15/alert_commands --out-json labs/lab02/data/data_v15/sudo_audit_report.json
